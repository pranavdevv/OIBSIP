# Oasis Infobyte SIP Portfolio

Welcome to my project repository for the Oasis Infobyte Student Internship Program (OIBSIP). This repository contains all the tasks and projects I have completed during my internship under the **Java Development** track.

## Track: Java Development

This track focuses on building robust backend and standalone applications using Java, object-oriented programming principles, and database management. Below are the tasks I have successfully completed:

### 1. [Task 3: ATM Interface](./Java-Task3-ATMInterface)
A secure, console-based Java application simulating an ATM. 
- **Features:** PIN hashing, withdrawal, deposit, transfer, and transaction history logging.
- **Concepts used:** Object-Oriented Programming (OOP), Data Structures (ArrayLists), Exception Handling.

### 2. [Task 5: Digital Library Management System](./Java-Task5-DigitalLibraryManagement)
A comprehensive web-based application to manage a digital library.
- **Features:** Admin/User roles, book issue/return management, automated fine calculation, and advance booking capabilities.
- **Tech Stack:** Java 17, Spring Boot 3.5, Spring Data JPA, SQLite, Thymeleaf, HTML/CSS.
